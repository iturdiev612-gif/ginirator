# Найди пару ✦

Браузерная игра на память на HTML, CSS и JavaScript. Без сборки и зависимостей.

## Запуск

Откройте `index.html` в современном браузере. Для публикации на GitHub Pages загрузите файлы в репозиторий и выберите ветку в Settings → Pages.

## Возможности

- Поля 4×4 (8 пар), 6×6 (18 пар), 8×8 (32 пары).
- Три темы: природа, еда, космос и приключения.
- Время с первого открытия, отдельные счётчики ходов и кликов. Один ход — две открытые карточки.
- Несовпавшие карточки закрываются через 850 мс. На это время поле блокируется.
- Пять лучших результатов для каждой сложности: сначала по ходам, затем по времени. Темы используют общий рейтинг сложности.
- Рекорды в localStorage; при недоступном хранилище игра продолжает работать, результаты остаются в памяти вкладки.
- Адаптивная сетка, управление Tab/Enter/Space, поддержка уменьшения анимации.

Смена темы или сложности начинает новую игру. Таймер продолжает отсчитывать время в фоновой вкладке. При запуске через file:// поведение localStorage зависит от браузера; для стабильного хранения используйте статический HTTP-сервер или GitHub Pages.

## Структура

- `index.html` — интерфейс.
- `style.css` — оформление и адаптивность.
- `game.js` — механика, перемешивание Fisher–Yates и хранение результатов.
